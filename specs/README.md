# specs/

Un dossier par fonctionnalité, créé par `/specify` : `specs/<NNN>-<slug>/`.

Fonctionnalités déjà spécifiées et livrées :

- `001-suivi-circuit-pj` : suivi des pièces justificatives d'un circuit de validation.
- `002-habillage-visuel` : habillage visuel de l'écran de suivi.
- `003-traitement-pj` : traitement d'une PJ (valider, rejeter, suspendre, reprendre, réouvrir) depuis l'écran de suivi.

(numéro suivant : `004`).
